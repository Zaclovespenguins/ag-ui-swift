## Integration follow-ups

- The original multimodal assertion failure was reproduced before changing it. Both legacy-image tests now assert translated image sources and MIME types.
- B5 contained a duplicate-JSON-key fixture that could select the valid content value. The fixture now supplies each key once.
- Both HTTP run entry points reject truncation, including an unfinished final run after historical replay. The new direct-run regression failed before the fix. An empty content-type header is rejected without an indexing trap.
- Activity stripping preserves B7's protocol version. New assertions failed before this fix. B9's HTTP fixtures now include terminal events, as required by B13.
- A producer's `RUN_ERROR`, including a late error after `RUN_FINISHED`, reaches failure subscribers and `runAgent` as `AgentRunError`. It remains distinct from consumer protocol rejection. A new run resets recorded outcomes and failures.
- Cancellation errors, transport cancellation, and local abort use cancellation callbacks. Both view models handle local cancellation without setting `lastError`, and a late producer error clears the cancelled flag. Behavior regressions were observed before these fixes.
- The 1,000-event throughput fixture still verifies every event but simulates network delay every 1,024 bytes rather than every byte.
- Verifier diagnostics are debug-build-only. New public warning values are hashable and documented. A focused naming/fixture cleanup reduced lint errors without restoring the deleted lint configuration.

### Reproduce reference validation

The reference dependencies are installed in a temporary directory rather than added to the Swift package:

```sh
npm install --prefix /tmp/agui-reference --ignore-scripts \
  @ag-ui/core@1.0.3 @ag-ui/encoder@1.0.3 zod@3.25.76 ajv@8
curl -fLsS \
  https://raw.githubusercontent.com/ag-ui-protocol/ag-ui/85a427d0558d0b117191690bad287da299acc91d/docs/spec/1.0/schema.json \
  -o /tmp/agui-schema.json
AGUI_WIRE_OUTPUT_PATH=/tmp/agui-swift-wire.json \
  swift test --filter ReferenceSDKWireTests
node scripts/validate-wire-reference.cjs \
  /tmp/agui-reference/node_modules /tmp/agui-swift-wire.json /tmp/agui-schema.json
```

The test exporter writes fixture data only when `AGUI_WIRE_OUTPUT_PATH` is explicitly set. These are narrow compatibility checks, not the complete C8 conformance harness.

## Compatibility decisions and remaining work

- `ToolCallResultEvent.content` is now `String?`; read `resultContent` for text or parts. Existing string initializers remain. This is a source-breaking public API change.
- `InterruptError.duplicateEntries(ids:)` can require updates to external exhaustive switches. `onRunCancelled` has a default implementation.
- Empty state, tools, and context are omitted. `forwardedProps` remains encoded as `{}` by default. Empty-state omission has schema coverage but no live adapter smoke test.
- Direct JSON encoding can preserve activity messages for local representations. The builder and every package send boundary strip them, including protocol version preservation when creating a stripped copy.
- Flattening joins text parts with newlines, returns warnings for dropped non-text parts, and inserts no placeholders. Warning delivery remains caller-owned until C7/C2 integration.
- A whole null resume payload is treated as omitted; nested null values remain data. This matches the pinned schema.
- Automatic stream resumption is removed. The three retry tests that asserted `Last-Event-ID` were intentionally replaced with no-resumption coverage. Legacy explicit cursor/header APIs remain available for compatibility.
- C1–C9 work remains as described in the implementation plan, especially C1 attribution/subagents, C2 version negotiation, C3 usage, C4 metadata, C6 capabilities, C7 warning routing, and the full C8 harness. `Tool.parameters` optionality and public role-string tightening remain deferred in `B12_SCHEMA_DIFF.md`.
